Insert this CSS into your CSS file

```css
@font-face {
  font-family: 'Comic Sans MS';
  src: url('https://raw.githubusercontent.com/stangertrashcan2003/Comic-Sans-MS-Host/main/Comic-Sans-MS.ttf') format('truetype');
  font-weight: normal;
  font-style: normal;
}
```

Then use this for applying the font in your CSS

```css
example {
  font-family: 'Comic Sans MS', cursive, sans-serif;
}
```
